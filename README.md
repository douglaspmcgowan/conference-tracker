# conference-tracker

Submission deadlines, locations, and requirements for **131 conferences and journals** across HCI, engineering design, AI / ML, visualization, manufacturing, and cognitive science.

**Live:** [conference-tracker-rho.vercel.app](https://conference-tracker-rho.vercel.app/)

## What it is

A single-page tool with four views over the same dataset:

- **Timeline** — horizontal Gantt with deadline → notification → conference dates per row, color-coded by field. "TODAY" axis line. Sorted by next deadline.
- **Cards** — filterable grid with countdown chips, tier badges, fit-for-you note, status pill, star + notes.
- **Table** — sortable by name / tier / deadline / conference start.
- **Map** — equirectangular world map. City markers scaled by conference count, colored by dominant field.

Plus filters (field, tier, time window, full-text search, starred-only), sort dropdown, dark mode, **iCal export** at `/cal.ics`, **per-conference notes + submission status** (localStorage), and **shareable filtered URLs** via hash state.

## Data

`data/conferences.js` is generated by `scripts/refresh-data.ts`, which reads `research/agent-{1..4}-*.md` (the JSON block at the end of each), dedupes by id, normalizes fields/tiers/dates, and sorts by next deadline. The four research files are the output of four parallel deep-research agents — one per cluster (HCI / Engineering Design / AI-ML / Viz-Mfg-CogSci).

A scheduled remote agent re-runs the research and merge every 12th and 26th of the month at 14:00 UTC.

Field shape per entry:

```js
{
  id: "chi-2027",
  name: "CHI",
  fullName: "ACM Conference on Human Factors in Computing Systems",
  year: 2027,
  fields: ["HCI"],
  tier: "A*",                       // "A*" | "A" | "B" | "industry" | "journal"
  abstractDeadline: "2026-09-04",   // optional
  deadline: "2026-09-11",
  notification: "2026-12-15",
  conferenceStart: "2027-04-25",
  conferenceEnd: "2027-04-30",
  location: { city: "Yokohama", country: "Japan" },
  format: "PDF, double-blind, ACM single-column",
  pageLimit: "no limit (typ. 10–15)",
  acceptanceRate: 0.26,
  blind: "double",
  link: "https://chi2027.acm.org/",
  fit: "Generative tools, design support, AI-assisted authoring",
  confidence: "verified"            // "verified" (≥2 sources) | "likely" | "estimated"
}
```

## Stack

- Single-file Express server (`server.ts`) — all HTML, CSS, and client JS as inline template literals
- `data/conferences.js` — single source of truth (generated output, deliberately left as JavaScript)
- TypeScript with no build step: Node runs `.ts`/`.mts` directly by stripping types, which is why `engines.node` is `>=22.18.0 <23`
- No bundler, no framework
- Deployed on Vercel as a serverless function

```
.
├── server.ts                  # Express app: API + iCal + page builder + getCSS + getJS
├── data/conferences.js        # generated; do not edit by hand
├── scripts/refresh-data.ts    # rebuild data from research/*.md
├── research/
│   ├── agent-1-hci.md
│   ├── agent-2-engineering-design.md
│   ├── agent-3-ai-ml.md
│   └── agent-4-viz-mfg-cogsci.md
├── tests/verify-live.mts      # Playwright e2e (52 checks)
├── tests/a11y.mts             # axe-core gate, both themes
├── tests/theme-first-paint.mts # no-JS first paint matches the settled theme
├── tests/floor-measure.mts    # quality-floor counts over the served page
├── tests/computed-style-oracle.mts # paint-property digest, per theme
├── tsconfig.json
├── vercel.json
└── package.json
```

## Run locally

```bash
npm install
node server.ts
# → http://localhost:3010
```

Endpoints:

| Path | Returns |
|---|---|
| `/` | The page |
| `/cal.ics` | All deadlines + conference dates as iCalendar (RFC 5545) |
| `/cal.ics?ids=chi-2027,uist-2026` | Subset by id |
| `/api/conferences` | JSON of all entries |
| `/health` | `ok` |

## Refresh the data

```bash
node scripts/refresh-data.ts
# → wrote 131 conferences across 14 fields
```

After editing any `research/*.md` file (or after the scheduled remote agent does), run the merge script and commit `data/conferences.js`. Vercel auto-deploys from `main`.

## Conventions

- Single accent color (`--accent: #2D5BFF`); used on <5% of the page
- Hairlines (`rgba(...,0.08–0.10)`) between sections, no box borders
- Asymmetric hover timing (120ms in / 240ms out)
- Tabular figures for dates and counts (`font-variant-numeric: tabular-nums`)
- Old-style figures in prose (`onum`)
- Warm-darks dark mode (no inverted slate)
- Grain overlay at 3% opacity
- `:focus-visible`-only ring; `prefers-reduced-motion` honored

The universal interface floor these sit on is `~/.agents/DESIGN.md`; project-specific rules are in `DESIGN.md` in this repository.
